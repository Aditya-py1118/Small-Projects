first it will divide the stored data that in 2 parts through middle point then when the user enters a value (searching for a data)
it will then first check that in which group the given data falls in by comparing it with the mid point if it is lower than
mid point then it means its in the min range of the data and if its greater than the mid point then it means it is 
in the maximum range so this reduces the workload by 50%. Thank you
